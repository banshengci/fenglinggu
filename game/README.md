# 《风铃谷》开发说明（v1.2 计划书全面完成）

Godot 4 **全平台开放世界**单机田园生活冒险。

## 运行

Godot 4.3 导入 `game/project.godot` → F5

```powershell
node tools\check_data.mjs
python tools\gen_content.py
godot --headless --path game -s res://tools/smoke_test.gd
```

## 操作

| 键 | 功能 |
|---|---|
| WASD / 左摇杆 / 触屏摇杆 | 移动 |
| E / A / 点击 | 交互 |
| 1–4 | 快捷栏 |
| I / C | 背包 / 合成 |
| M | 开放世界地图（快速旅行 / 远足） |
| U | 图鉴 · 技能 · 成就 · 动物 |
| O | 角色外观自定义 |
| P | 拍照模式 |
| T / H / L / F2 | 睡觉 / 休整 / 读档 / 新周目+ |
| Esc | 暂停 |
