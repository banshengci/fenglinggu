# 《风铃谷》v2.0 版本规划（新内容 · 新玩法）

> 基线：v1.2 全平台开放田园（种田/矿洞/社交/牧场/五章主线）  
> 主题：**「风有了形状」**——把「风」做成可感知、可收集、可演奏的核心玩法  
> 原则：小步可玩、数据驱动、全平台一致；不破坏 v1 存档（可继承）

---

## 1. 版本愿景（一句话）

在 v1「把风铃修回来」之后，让玩家 **收集风、演奏风、乘风远行**，并把山谷长成自己的样子。

**支柱**
1. **风之语** — 可收集的风元素 → 音色/演奏/共鸣  
2. **远行** — 空中航线 + 群岛 DLC 级区域  
3. **匠心** — 烹饪/裁缝/木作深度与称号  
4. **羁绊** — 恋爱婚礼 + 镇子共建议会  

---

## 2. 新系统（玩法）

### 2.1 风之语（核心新系统）
| 概念 | 说明 |
|---|---|
| 风语 | 8 种基础风语（微风/晨风/湖风/林风/谷风/雪风/星风/心风） |
| 获取 | 天气事件、指定地点聆听、NPC 赠礼、过场 |
| 用途 | ① 风铃**作曲** ② 工具**风附魔** ③ 招来特定天气/生物 |
| 演奏 | 简易 8 格音序：连出「风之旋律」触发全镇加成（生长/好感/掉率） |
| 图鉴 | 风语 + 音色收集册；集齐给称号「听风者」 |

**体验**：每天出门听风 → 傍晚在铃塔弹一段 → 镇民跟着点头。

### 2.2 空中远行（开放世界升级）
- **热气球航线**：镇 ↔ 云台 ↔ 浮岛农场 ↔ 星风崖  
- **浮岛农场**：空中温室，反季种植、稀有风语花  
- **滑翔翼**（星风崖下山）：轻竞速小游戏，收集云絮  
- 世界地图增加 **Z 轴高度层** 图例（地面 / 空中）

### 2.3 秘境 · 风蚀迷宫（轻 Roguelite）
- 每周随机生成 3 层「风蚀迷宫」（雾林/矿脉/湖底入口轮换）  
- 携带 3 件工具 + 有限补给进入；**不掉落**存档物资（休闲）  
- Boss「风蚀核心」掉**星风铃**部件  
- 通关记星：1–3 星速度/收集，可重复刷装饰

### 2.4 匠心三业
| 技能 | 新玩法 | 产出 |
|---|---|---|
| 烹饪 | 火候 QTE 小条 + 配方连作 | 料理图鉴、宴席 |
| 裁缝 | 布料染色 + 版型 | 外观套、节日盛装 |
| 木作 | 榫卯拼装小游戏 | 高级家具、建筑改外观 |

与 v1 六技能打通：农耕/垂钓/采集/采矿/烹饪/牧歌 + 三匠心。

### 2.5 羁绊扩展
- 好感 6 心 → **告白** → 伴侣同行（帮你浇水/捡拾）  
- **婚礼**（季节限定仪式）与婚后小屋皮肤  
- 镇子**议事会**：投票修缮（广场、图书馆、温室）解锁全镇加成

### 2.6 节令联赛（赛季长线）
- 每季 1 场正式大赛 + 周常小赛  
  - 钓王杯 / 厨神会 / 萌宠展 / 观星夜 / 作曲祭  
- 排行板（本地 + 可选异步幽灵成绩）  
- 奖杯陈列室 + 赛季称号

## 4. 系统改进（v1 痛点）

1. **UI/UX**：图标全贴、背包筛选、地图图例、任务追踪可折叠  
2. **时间**：可选「悠闲日长」；过场可跳过  
3. **农耕**：洒水器升级树、堆肥桶、蜂箱联动  
4. **矿洞**：可标记层、电梯（迷宫外）、矿车小捷径  
5. **触屏**：自定义 HUD 按钮布局  
6. **无障碍**：色盲配色、按键重绑、字体放大  
7. **云存档槽**（平台本地导出/导入文件）  
8. **性能**：粒子密度档、批量实例化植被

## 5. 内容排期（建议 3 个里程碑）

### M2-A 聚焦可玩（4 周）
- 风语收集 + 简易演奏 4 音  
- 浮岛农场 1 块 + 热气球 2 站  
- 告白/婚礼最小闭环（1 名角色全事件）  
- UI 图标与筛选完成  
**验收**：能收集风语并弹一段触发加成；能飞到浮岛种一季反季菜。

### M2-B 深度与赛（4 周）
- 风蚀迷宫随机层 + 1 Boss  
- 匠心三业 QTE 与配方  
- 钓王杯/厨神会联赛 + 奖杯架  
- 伴侣同行 AI  
**验收**：每周有事可干；联赛能上榜（本地）。

### M2-C 打磨发行（3 周）
- 音乐/音效包扩  
- 全平台包体与商店图更新（「风之语」资料片宣传）  
- 幽灵成绩、无障碍、云导出  
**验收**：可称 v2.0 更新上线。

## 6. 明确不做（本轮红线）

- 多人联机 / 共建  
- 沙盒无限世界生成  
- 硬核魂类战斗  
- 内购/赛季通行证

## 8. 成功标准

1. v1 玩家 1 小时内上手风语并完成一次演奏  
2. 新玩家 Demo「听风—乘风—奏乐」三连有记忆点  
3. 赛季周留存：每周至少 1 场可参加赛事  
4. 无新卡死类 UI 问题（Modal 规范延续）
