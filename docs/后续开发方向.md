# 《风铃谷》后续开发方向（基于当前状态）

> 基线：本地可导出 Win/Web/Android · 玩法与数据基本齐 · 刚修「合成面板黑屏关不掉」  
> 原则：**先稳手感与包体，再扩内容，最后发版**；小步可验收，避免再堆一次性大改。

---

| 维度 | 状态 | 风险 |

| 玩法闭环 | 种田/矿洞/社交/合成/建造/开放地图已通 | 配方多、面板易挤爆（已修合成，其它面板待扫） |

## 1. 阶段路线图（建议 4 个冲刺）

### 冲刺 A — 可玩性稳定（先做，约 2–3 天）
目标：**任何弹窗都能关，触屏/键鼠/手柄一致。**

1. **统一 Modal 规范**（合成已改，照抄到）
   - 背包 / 商店 / 图鉴 / 设置 / 世界地图 / 对话
   - 每个面板：固定尺寸 + 滚动 + 右上「关闭」+ `use_tool`/`ui_cancel`/快捷键关闭
   - `close()` 统一恢复 `paused = false`，防止卡死
2. **输入分层**
   - 有 Modal 时：世界 `_unhandled_input` 直接 return（防「关了又被工作台打开」）
   - 触屏增加屏幕按钮：背包 / 合成 / 地图 / 关闭
3. **回归清单**（人工 10 分钟）
   - 开/关 各面板 × 触屏点按 × Esc × 快捷键  
   - 矿洞里被围殴时开背包能否关掉  
   - 对话连点是否误关
4. 小修：ObjectDB 2 个泄漏（退出时），不阻塞但清一下

**验收**：安卓真机 + Win 上「打开任意 UI → 100% 能关」。

---

### 冲刺 B — 构建与仓库脱钩（约 1–2 天）
目标：**公司/家里/无 Godot 机器也能出包。**

1. 确认并 `git push`（含 `7b5964d` 与本次 UI 修复）
2. 部署 NAS Runner：`deploy/nas-runner/` + Gitea Token + `docker compose up -d`
3. 跑通 `.gitea/workflows/build.yml` 三任务：windows / web / android
4. 产物落盘规则：Actions 附件或 NAS 目录；记录 SHA 与体积
5. 可选：push 触发冒烟（headless 启动 + smoke_test）

**验收**：仅 push 后在 Gitea 下载三端包，且大小合理（Win ~300MB / APK ~250MB / Web 含 pck）。

---

### 冲刺 C — 体验与内容补齐（约 3–5 天）
目标：**Demo 有记忆点，前 30 分钟不空虚。**

1. **资产缺口**（workbuddy 继续）
   - 挥工具 / 受击 帧（主角 + NPC）
   - 矿岩 3 套独立贴图
2. **新手前 30 分钟**
   - 目标追踪与工具快捷栏更醒目（1–4 显示图标）
   - 第一枚风铃剧情节奏：缩短跑图、材料好拿
   - 教学只保留 5 步，其余进「图鉴」
3. **系统深化（小而美）**
   - 集市周溢价可见化（出货箱旁小黑板）
   - 共鸣同族差异（同科作物种一圈加成）
   - 钓鱼手感：节奏条 + 触屏按钮「起竿」
4. **手柄/触屏真机走查**一轮，记进 PROGRESS

**验收**：陌生人试玩 20 分钟能独立完成「翻地→收获→下矿→修铃」。

---

### 冲刺 D — 发布准备（约 2–3 天）
目标：**能对外发 Demo。**

1. 调试签名 → 正式 keystore（或 TestFlight/自签说明）
2. Steam/网页商店素材：胶囊图、6 张截图、GIF 三循环（已有 marketing 部分）
3. 版本号与更新日志模板；导出 `CHANGELOG.md`
4. 设置里：语言、音量、休闲辅助、**性能档**（关闭天气叠色/粒子）
5. Web 版加载条与「点击开始」手势（避免移动浏览器自动播放限制）
6. iOS：暂用 Web 给 iPhone；有 Mac 再出 IPA

**验收**：可给出下载链接 + 一页「怎么玩/按键表」。

## 2. 技术原则（避免再踩坑）

| 原则 | 说明 |
|---|---|
| UI 一律可关闭 | Modal 必须有可见关闭钮 + 至少两种关闭输入 |
| 列表必滚动 | 配方/图鉴类禁止撑爆布局 |
| 工具调用克制 | 一次 1–2 个工具；先读再改，避免重复调用 |
| 数据驱动 | 新内容优先改 JSON + `gen_content.py`，少改 GDScript |
| 每冲刺可验收 | 有一条真机/无头可执行的检查 |
| 大改不进主支 | 菜单重做、战斗扩展等单开分支 |
