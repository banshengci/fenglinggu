# 《风铃谷》美术需求清单（交 workbuddy）

> 游戏：全平台 2D 开放田园生活《风铃谷 / Wind Chime Valley》  
> 引擎：Godot 4 · 像素/手绘混合卡通  
> 用途：风格锚定 + 素材清单 + 规格 + 优先级  
> 交付格式：PNG（透明底）+ 必要时 Aseprite 源文件；统一放进 `game/art/`

---

## 0. 全局风格锚（所有图都按这个来）

| 项 | 要求 |
|---|---|
| 气质 | 温暖田园绘本 + 轻像素；吉卜力式软光，**不要**暗黑/赛博 |
| 线条 | 可无描边或细暖褐描边（非纯黑） |
| 调色主色 | 草绿 `#8FB56F` · 纸奶油 `#F3EAD3` · 木褐 `#6B5340` · 铃金 `#E8C87A` · 湖蓝 `#8FC0D8` · 陶红 `#C07850` |
| 季节变奏 | 春青绿 / 夏暖金 / 秋蜜褐 / 冬蓝白 |
| 角色头身比 | 2–3 头身 Q 版 |
| 光 | 无硬阴影；黄昏/洞内用暖冷对比 |
| 禁止 | 水印、文字烙印、复杂写实、恐怖血腥 |
| 关键帧已有 | `game/art/keys/`：town_square · garden_dusk · mine_crystal（对齐用） |

**导出规格**：像素风 16/24/32 网格；放大导出 @1x（逻辑）+ @2x（高清）。UI 矢量感可 1x。命名 `snake_case.png`。
