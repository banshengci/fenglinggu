最快上手

手机上没有开发者账号时，推荐顺序：

① 先装 Web 版当 App 用（零签名）→ ② 需要原生 IPA 再用 AltStore 自签。

自签步骤（AltStore）

  1. 电脑装 AltServerWindows / Mac 官网下载，同一 Wi-Fi 连上 iPhone
  2. 手机装 AltStoreAltServer → Install AltStore → 你的设备，登录免费 Apple ID
  3. 获取 IPA云端构建产物 fenglinggu_0.01.ipa，传到手机（文件 / 网盘）
  4. AltStore 打开 IPA「我的应用」→ + → 选中 IPA → 输入 Apple ID 签名安装
  5. 信任证书设置 → 通用 → VPN 与设备管理 → 信任你的 Apple ID
  6. 每 7 天续签打开 AltStore 点 Refresh，或重复第 4 步

备选：Sideloadly

与 AltStore 类似，电脑插线安装更稳。拖入 IPA → 填 Apple ID → Start 即可。

为什么 iOS 要自签？

上架 App Store 需付费开发者账号与审核。个人自用走「免费 Apple ID + 侧载」完全够用，代价是 7 天续签。

常见问题

Q：没有开发者账号能装吗？
能。用免费 Apple ID 自签，不发布商店。

Q：会掉签吗？
会，约 7 天。AltStore 后台可自动续；或到期重签。

Q：不想折腾签名？
Safari 打开 Web 版 → 分享 → 添加到主屏幕，当 App 图标用。

Q：能永久签吗？
TrollStore / 越狱可，设备与系统版本受限，不作默认路径。
