**关键教训（很值钱）**
1. **连通域法对「相接主体」完全失效**：岩心守卫 6 帧肩并肩 → `merge_gap=30` 时连成 1 坨；雾蝠翼尖相接同理。改用 `strip_split.py` 的竖直投影，一次搞定 6 帧。
2. **`merge_gap` 是双刃剑**：家具板里 4 幅画纵向间距 28px < 阈值 34 → 两两误并成 2 个域。调小到 16 即正确切出 8 件。**先跑 `probe_decor_frames.py` 扫一遍 merge_gap 再定值**。
3. **生成模型会把「网格/多物件」画成带装饰相框的卡片**：fx/weather 两张板把每个效果套了一个圆角边框 → inset 内裁也去不掉（框在内容里层），只能**重出**（prompt 明确 "no border, no frame, no box, no card"）。
4. **淡色主体会被抠透**：史莱姆「受击」第 1 帧带一个白色闪光圆盘，把史莱姆描边打断 → 洪水填充从缺口漏进去，把奶油色填充抠没了，只剩一条细弧。重出该板（去掉白圆盘）。
5. `strip_split` 的「共同画幅」会让小特效在一张大画布上显得极小 → 等距网格改用 `grid_slice` 让每格独立成画幅，视觉重量才一致。

**最关键的教训：生成模型对「N 件网格」的排布完全不可预测**
同一天出的 12 件板，可能是 4x3、3x4、2x5、5x2、6x2 中任意一种；料理 4 板里 p1/p2/p4 都是 **2 列×5 行**（不是 5x2），固定网格切出来全是「一格里挤 2~3 件」。
→ **结论：多物件板图一律优先用 `auto_slice.py`（连通域 + 阅读顺序 + 透明底 + 逐件正方形），不要先猜 cols/rows。** 只有确认是规则网格且物件不溢格时才用 `grid_slice.py`。

**`auto_slice.py` 调参要点（都踩过）**
1. `merge_gap` 不能大：40 会把同列相邻物件并成一条；**8 是甜点区**。
2. `merge_gap=0` = 完全不合并（原始连通域）。当大件包围盒互相重叠时，**连 gap=0 的 bbox 合并都会级联成一坨**（作物 p1 的 12 件被并成 3 个）→ 必须用 `merge_gap=0` 跳过合并。
3. 检测数 > 期望数时，取**面积前 N** 再按阅读顺序排（碎屑/叶片不会顶掉主体）。
4. **物件放在一张大纸卡上时**（种子 p4），整张卡会被当成前景 → 1 个域。把 `tol` 提到 45~52 让卡片掉出前景，只留彩色小袋 → 12/12。
5. 背景纸纹理重时（作物 p1），`tol` 反而要**调低**（22→15），否则纹理连成一片。

**自动命名撞名风险**：ImageGen 文件名 = prompt 前缀 + 时间戳。本轮出现两次同前缀（`A_second_set_of_twelve_separat_...` 用于作物/鱼/种子三张板），靠时间戳不同才没覆盖。**并发出图时务必让每条 prompt 前 ~30 字符不同。**

## 收口：主角 / NPC 行走帧（四向 × 4 帧）+ 引擎帧动画接入

**起因**：`player_refsheet.png` 是整幅插画，无法自动切帧。改为**出规范化 4×4 板图**再切片。

**板图 prompt 必写四条约束**（缺一条就会生成不可切的整幅插画或帧间尺寸不一）
- `exactly 4 columns and 4 rows, 16 equal cells`
- `exactly the same height, same size, same scale in all 16 cells`
- `No props or accessories that change silhouette`
- `No borders, no grid lines, no captions, no text`
行顺序固定 down → left → right → up；列序即帧序（00 为静止帧）。

**新工具 `tools/slice_walk.py` 的三个非显然要点**
1. **全板统一 scale**：各帧各自 fit 会「呼吸抖动」。取宽高 90 分位做基准，且必须按**加 margin 后**的尺寸算（否则最大帧撑破画布，实测 paste 负偏移 -12）。
2. **脚底对齐**：按角色主体 bbox 底边落地（`py = out_h - 1 - nh + mb`，`mb = margin*scale`），**不是**按含 margin 的裁切框底边——后者让脚底漂移 7~10px。
3. **主体连通域折中 `keep_frac=0.15`**：只取最大域会被背景近似色（浅色衣物贴 `#F3EAD3` 纸底）把头身切断（down 行实测丢头，次域是主体的 73%）；整格前景又会把相邻行溢入的残片一起裁进来（残片仅占 0.5%）。→ 合并所有面积 ≥ 最大域 15% 的域。

**配套**：`tools/gen_walk_jobs.py`（9 板作业 JSON）· `tools/diag_cells.py`（逐格连通域诊断，用来定 keep_frac）· `tools/audit_walk.py`（4 判定：空帧 <8% / 同向高度极差 >18% / 四向均值极差 >25% / 脚底极差 >6px）。

**踩坑**：`set(lbl[:, -1:].tolist())` 报 unhashable list —— 切片 `[:, -1:]` 保留二维，要用 `[:, -1]`。
